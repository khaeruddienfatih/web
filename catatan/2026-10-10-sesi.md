# Catatan sesi 2026-10-10 — haji.biz setelah ganti theme ke GeneratePress

## Temuan
- haji.biz kini memakai theme **GeneratePress** (sebelumnya LandingPress). Hosting: WordPress.com (wpcomstaging).
- **Auth REST haji.biz sekarang jalan** dengan `HAJIBIZ_WP_USER` / `HAJIBIZ_WP_APP_PASSWORD` (users/me = administrator).
- Endpoint `eh/v1/hf` (snippet WPCode `wordpress/wpcode-uae-rest.php`, ada di branch `claude/elegant-brown-sfgkdf`) aktif:
  header UAE = post 423, footer UAE = post 419.
- Penyebab tampilan berantakan: 7 halaman masih memakai template `page_landingpress.php` (tidak ada di GeneratePress)
  → jatuh ke layout default: judul halaman tampil, sidebar kanan, konten sempit.
- Gambar Cloudinary tampak rusak di screenshot hanya karena egress sandbox memblokir res.cloudinary.com (bukan masalah situs).

   Untuk mengembalikan: set `template` ke `page_landingpress.php` lagi (tidak berguna di GeneratePress).

   judul artikel/sidebar warna brand + Poppins, tombol Cari biru, judul ganda di Lokasi Kantor disembunyikan.
